# Garage Sessions

Mobile-first offline-capable workout tracker. No subscriptions or external accounts. Open using GitHub Pages (Settings → Pages → Deploy from branch → main / root).

Includes workout plans, logging, carry-forward weights, session notes, technique tips, charts, progression prompts, history, editable plans, backup/restore and a PWA shell.

Data is stored locally per browser/device using localStorage. Export backups regularly. Apple Health needs a native HealthKit bridge and is not yet implemented. Suggestions are informational, not medical advice.
